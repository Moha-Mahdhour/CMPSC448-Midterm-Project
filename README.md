# CMPSC448-Midterm-Project

Who Wrote It? Identifying LLMs (Claude, GPT, DeepSeek) from their responses with a CNN and an LSTM.

- **Report:** `AlMahanad_AlMahdhour_Midterm_Report_Main.pdf`
- **Code:** the `RQ` folder has one notebook per research question (`RQ1.ipynb` to `RQ4.ipynb`). The full notebook with everything in one place is `notebooks/model.ipynb`.
- **Data:** the `data` folder has the prompts (`prompts.csv`), the answers from each LLM (`responses/`) and the final dataset used for training (`dataset.csv`).

## Running the code

```bash
pip install -r requirements.txt
jupyter notebook
```

Then open any notebook in `RQ/` or `notebooks/` and run all cells.
